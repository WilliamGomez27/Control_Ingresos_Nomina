🔒 ¿Cómo crear un token 100% seguro? Recomendado

Para tu total tranquilidad, crea un token con permiso exclusivo a Gists. De esta manera, el token no tendrá acceso a ningún repositorio, código ni proyectos privados de tu cuenta de GitHub:

  1. Ve a github.com → Settings → Developer Settings → Personal Access Tokens → Fine-grained tokens.
  2. En Repository access elige: Public Repositories o None.
  3. En Account permissions busca Gists y asígnale: Read and Write.
  4. Genera el token (inicia por github_pat_... o ghp_...) y pégalo arriba.
🛡️ Tu token se almacena únicamente en tu propio dispositivo (localStorage). Abrir GitHub Tokens ↗
